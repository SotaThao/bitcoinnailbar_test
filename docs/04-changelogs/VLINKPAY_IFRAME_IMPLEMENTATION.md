## 🔧 **URL Structure (VLINKPAY GIFT CARD)**

```
{SANDBOX_ENDPOINT}/embedded/payment-init
  ?amount={amount}
  &merchantOrderCode={merchantOrderCode}
  &email={customerEmail}
  &merchantRefCode={merchantRefCode}
  &timestamp={timestamp}
  &orderRedirectUrl={orderRedirectUrl}
```

### **Parameters**

| Parameter | Generated By | Example |
|-----------|-------------|---------|
| `amount` | Frontend (tier price) | `5000000` |
| `merchantOrderCode` | Backend auto-gen | `ORDER-1737468234-A1B2C3D4` |
| `email` | User input (modal) | `user@example.com` |
| `merchantRefCode` | Admin settings | `BTCNAIL-MERCHANT-001` |
| `timestamp` | Backend | `1737468234567` |
| `orderRedirectUrl` | Admin settings | `https://site.com/membership?payment=success` |

**Note**: No checksum required per client confirmation.

## 🔄 **Complete User Flow**

### **Step 1: Choose Membership Tier**
- User clicks "Join Now" on any tier card
- Frontend calls `POST /payment/create-link`
- Backend generates redeem code + payment URL template

### **Step 2: Email Collection**
- `PaymentModal` opens with email form
- User enters email (required, validated)
- Clicks "Tiếp Tục Thanh Toán"

### **Step 3: IFRAME Payment**
- Modal replaces email form with IFRAME
- IFRAME loads: `{paymentUrl}&email={userEmail}`
- User completes payment in VLINKPAY

### **Step 4: Success Handling**
- VLINKPAY sends postMessage to parent window
- Modal listens for `payment-success` event
- Shows success popup with redeem code
- Closes modal
- Auto-scrolls to `#redeem-section`

### **Step 5: Code Redemption**
- User receives code via email (VLINKPAY sends)
- User enters code in Redeem Section
- Membership activated with tier priority

## 🐛 **Known Issues & Solutions**

### **Issue 1: IFRAME Not Loading**
**Cause**: Sandbox endpoint incorrect or CORS issue  
**Solution**: Verify endpoint URL in admin settings, check browser console

### **Issue 2: postMessage Not Received**
**Cause**: VLINKPAY iframe not sending message  
**Solution**: Contact VLINKPAY support for postMessage integration

### **Issue 3: Email Not Sent**
**Cause**: VLINKPAY email service not configured  
**Solution**: Verify with VLINKPAY that email sending is enabled
