## 🔧 **TECHNICAL DETAILS:**

### **Shared Dependencies:**
All Wave 1 modules use:
- `_shared_kv.tsx` → `kvAdmin` (admin KV table)
- `_shared_constants.tsx` → `KV_TABLE_ADMIN`
- `_shared_supabase_client.tsx` → Direct Supabase for deletes

### **KV Storage Pattern:**
- **Table:** `kv_store_89edbd69` (admin)
- **Prefixes:** `branch:`, `service:`, `review:`
- **ID Format:** `{prefix}:{timestamp}`

### **Module Structure Pattern:**
```typescript
import { Hono } from 'npm:hono@4.6.14';
import { kvAdmin as kv } from './_shared_kv.tsx';

const app = new Hono();

// GET route - list all
app.get('/make-server-84f9c112/{resource}', async (c) => {
  const items = await kv.getByPrefix('{prefix}:');
  return c.json({ success: true, data: items });
});

// POST route - create
app.post('/make-server-84f9c112/{resource}', async (c) => {
  const body = await c.req.json();
  const id = `{prefix}:${Date.now()}`;
  const item = { id, ...body, createdAt: new Date().toISOString() };
  await kv.set(id, item);
  return c.json({ success: true, data: item });
});

// DELETE route - remove (if applicable)
app.delete('/make-server-84f9c112/{resource}/:id', async (c) => {
  const id = c.req.param('id');
  const { error } = await supabase.from(KV_TABLE_ADMIN).delete().eq('key', id);
  return c.json({ success: true });
});

export { app as {resource}App };
```
